# clocksync — 同步调用链时钟偏移校正复核

复核一份模拟的同步调用链：2～8 个服务、至多 100 个 span。每个 span 给出
所属服务、父 span、以及该服务**本地时钟**上的整数起止时刻；每个服务有允许
的整数时钟偏移区间，且恰好一个服务锚定为 0。后端把“校正后每个子调用完整
落在父调用区间内”化成**差分约束**，用 Bellman-Ford 求解：

- **可行**：返回按服务 ID 字典序最小的整数偏移向量、校正后的 span
  （前端据此绘制时间线）以及每条父子约束的起点/终点余量。
- **不可行**：返回一个由真实输入约束构成的矛盾环（环上每条边都标注其来源
  ——某条父子约束或某个偏移界），权重和为负即不可行的证明；
  此时**不绘制任何校正时间线**。

## 目录结构

```
cmd/server/            HTTP 服务入口（ADDR、STATIC_DIR 环境变量可配）
internal/solver/       差分约束求解器（可行性、字典序最小解、矛盾环抽取）
internal/api/          POST /api/solve、GET /api/health、静态托管
web/                   Svelte + Vite 复核页面
```

## 约束建模

设服务 `s` 的偏移为 `x[s]`（校正时刻 = 本地时刻 + 偏移）。对子 span `c`
（服务 `cs`）与父 span `p`（服务 `ps`）：

```
子起点 + x[cs] ≥ 父起点 + x[ps]   ⇔   x[ps] - x[cs] ≤ c.start - p.start
子终点 + x[cs] ≤ 父终点 + x[ps]   ⇔   x[cs] - x[ps] ≤ p.end   - c.end
偏移界  lo ≤ x[s] ≤ hi            ⇔   x[s] - 0 ≤ hi 且 0 - x[s] ≤ -lo
```

全部为 `x[v] - x[u] ≤ w` 形式。负环 ⇔ 无可行偏移；环即矛盾证据。
字典序最小解通过逐变量固定求得：固定 `x[0..i-1]` 后，`x[i]` 的最小可行值
等于对偶系统（`y = -x`）中 `y[i]` 的最大可行值，即 ZERO 源点最短路。

## 运行

```bash
# 后端（默认 :8080，自动托管 web/dist）
go run ./cmd/server

# 前端开发模式（/api 代理到 :8080）
cd web && npm install && npm run dev

# 生产：构建后由 Go 服务直接托管
cd web && npm run build && cd .. && go run ./cmd/server
```

## 测试

```bash
go test ./...
```

- `internal/solver`：随机小用例（2～3 服务）与**穷举全部整数偏移向量**对拍
  可行性与字典序最小解；对不可行用例**逐边核验矛盾环**——每条边都属于由
  输入重建的约束集、首尾相接、权重和为负；另有手算可验的确定性用例与
  输入校验用例。
- `internal/api`：可行 / 不可行 / 非法输入三类端到端用例，并断言不可行时
  响应中不含偏移、校正时间线与余量。

## 页面行为

- 编辑偏移界或 span 后，旧求解结果**立即失效**（结果被清空并提示重新求解）。
- 求解成功：时间线完全根据该次响应中的 `correctedSpans` 绘制，并列出每条
  父子约束的起点/终点余量。
- 求解不可行：仅展示矛盾环（每条约束标注来源与权重、总和为负），不绘制
  任何校正时间线。
